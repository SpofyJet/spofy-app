# Spofy

Приложение для VPN на Android, Windows, macOS и Linux. Работает с подпиской Spofy VPN и с любой другой подпиской или ключом для Xray.

**[Скачать последнюю версию](https://github.com/SpofyJet/spofy-app/releases/latest)**

| Система | Файл в выпуске |
|---|---|
| Android 7.0 и новее | `…-arm64-v8a.apk` — почти все телефоны; `…-armeabi-v7a.apk` — старые 32-битные; `…-x86_64.apk` — устройства на Intel и эмуляторы |
| Windows 10 и 11, 64 бита | `…-x64.exe` |
| macOS 12 и новее, Apple Silicon и Intel | `…-macos.pkg` |
| Linux: Ubuntu, Debian, Mint | `…-linux-amd64.deb`, для ARM — `…-linux-arm64.deb` |
| Linux: Fedora, openSUSE | `…-linux-x86_64.rpm`, для ARM — `…-linux-aarch64.rpm` |

Как поставить на Linux и macOS — в описании выпуска.

## Чем Spofy лучше других приложений

Перед тем как писать своё приложение, мы разобрали, как устроены популярные клиенты. Ниже — что в них встречалось и что у нас сделано иначе. Все числа — замеры на наших стендах: эмуляторе Android, машинах Windows и Linux.

| | В разобранных приложениях | В Spofy |
|---|---|---|
| Статус «подключено» | показывается, когда запустилось ядро: сервер может не отвечать, а на экране всё хорошо | «VPN работает» — только после ответа через туннель |
| Сервер перестал отвечать | перехода на другой сервер нет, менять приходится руками | приложение видит это по трафику и само уходит на другой сервер: 9–12 с, без нажатий |
| Смена Wi-Fi на мобильную сеть | туннель пересоздаётся, на это время трафик идёт без VPN | туннель тот же, 0 запросов мимо VPN из 51 |
| Защита от утечки при сбое | нет совсем, либо правила брандмауэра, которые остаются после падения и ломают интернет | «Без VPN — без интернета»: на Windows ядро убито 100 раз подряд — мимо VPN 0 запросов из 15 770. На Windows и Linux блокировка переживает падение службы и перезагрузку. Без этой настройки защита исчезает вместе с приложением и интернет не ломает |
| Локальный порт | прокси на `127.0.0.1` (иногда без пароля): любая программа на устройстве видит, что VPN включён, и узнаёт адрес выхода | в режиме VPN открытых портов 0, доступа к ядру со стороны нет |
| Ключи на диске | открытым текстом | только в зашифрованном файле; на Android и Windows ключ к нему хранит система |
| Обновление списка серверов | каждый раз скачивается целиком | если ничего не изменилось — 0 байт; список обновляется сам |
| Туннель | отдельная программа-прослойка между системой и ядром | туннель встроен в ядро, лишнего звена нет |
| Обновление приложения | без проверки подписи | подписано, файл сверяется дважды: при скачивании и перед установкой |

### Скорость

| | Замер |
|---|---|
| Повторное подключение | 0,11 с |
| Первое подключение с замером всех серверов | 1,8–2,6 с |
| Смена сервера | 0,05–0,23 с, туннель не пересоздаётся |
| Замер всех серверов подписки (19 серверов) | 2,0–2,9 с |
| Запуск приложения на Android | 0,84–1,01 с |
| Подключение кнопкой на Android | 0,7 с |

Задержка в списке серверов — это ответ по уже открытому соединению, то есть то, что вы почувствуете в работе, а не время первого рукопожатия.

### Что ещё

- **Бесперебойное подключение.** Одна настройка: приложение уходит с замолчавшего сервера и возвращается, когда он отвечает снова. Ваш выбор сервера при этом не меняется.
- **Выбор приложений** на Android: все через VPN, все кроме отмеченных или только отмеченные. Приложение, убранное из VPN, пройти через туннель не может.
- **Домашняя сеть при включённом VPN.** Роутер, сетевой диск и принтер открываются по имени.
- **Несколько подписок и свои ключи.** Переключение — одно нажатие.
- **Фрагментация** приветствия TLS не замедляет соединение: +0 мс.
- **Системный прокси** вместо VPN на Windows — по выбору; прежние настройки прокси возвращаются при любом выходе.
- **Обновления** на Android и Windows ставятся из приложения.
- **Автоподключение**, плитка быстрых настроек Android, значок в трее Windows, напоминание о конце подписки.
- **Отчёт для поддержки** одним нажатием: что сейчас происходит, без ключей и адресов подписки.
- **Тёмная и светлая тема, русский и английский.**
- **Без рекламы и сторонней аналитики.** Отчёт о неудачном подключении уходит только на адрес, который объявила сама подписка. Подписка его не объявила — приложение ничего не отправляет.

## Поддерживаемые протоколы

Ядро — наш форк Xray-core.

| Протокол | Транспорт и защита |
|---|---|
| **VLESS** | TCP (RAW), XHTTP, gRPC, WebSocket, HTTPUpgrade; TLS и REALITY, XTLS Vision, ECH |
| **Hysteria 2** | QUIC; Salamander, смена портов, проверка сертификата по отпечатку |
| **Trojan** | TCP (RAW), XHTTP, gRPC, WebSocket, HTTPUpgrade; TLS и REALITY |
| **VMess** | TCP (RAW), XHTTP, gRPC, WebSocket, HTTPUpgrade; TLS |
| **Shadowsocks** | AES-128-GCM, AES-256-GCM, ChaCha20-Poly1305, XChaCha20-Poly1305 |
| **Shadowsocks 2022** | 2022-blake3-aes-128-gcm, 2022-blake3-aes-256-gcm, 2022-blake3-chacha20-poly1305 |
| **WireGuard, SOCKS5, HTTP** | в подписке формата Xray JSON |

Как добавить сервер:

- **ссылка на подписку** — Xray JSON или список ключей, в том числе в base64;
- **ключи** `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` и `hy2://` — вставить в приложение, один или несколько;
- **кнопка на сайте** — ссылка `spofy://add/…` открывает приложение и предлагает добавить подписку.

Подписку в формате Xray JSON приложение не переписывает: маршруты и цепочки серверов остаются такими, какими их задал сервис.

## Как это проверяется

На каждой сборке идут закрытый стенд без интернета (83 проверки), эмуляторы Android 7.0 и 14, машины Windows, macOS и Linux: установка, подключение, смена сервера, падения ядра и службы, обновление с прошлой версии. Выпуск собирается только из коммита, который прошёл всё.
